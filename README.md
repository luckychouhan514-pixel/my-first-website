# Shivalaya Paper Workks — Static Website

A clean, dependency-free front-end rebuild based on the public information architecture that was inspected. It is not a copy of the original WordPress/PHP implementation.

## Run locally

Open `index.html` directly in a browser, or serve this directory with any static server. For example, from this directory:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Included pages

* `index.html` — Home
* `about.html` — Company overview
* `products.html` — Product catalogue
* `product.html?product=twisted-handle` — Dynamic product-detail template
* `contact.html` — Contact/enquiry form
* `career.html` — Career page

The forms are front-end demonstrations. Connect them to your email/CRM API before deploying.
